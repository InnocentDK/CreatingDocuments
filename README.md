# Invoice Template Editor

Приложение на Python для создания шаблонов счетов, заполнения данных и экспорта документов в **Word (.docx)** и **PDF (.pdf)**.

## Что умеет

1. Создавать шаблоны из блоков:
   - `Текст` — статичный блок;
   - `Поле` — блок с идентификатором, в который позже подставляется значение.
2. Помечать блок как неизменяемый (fixed value).
3. Выбирать сохраненный шаблон и заполнять изменяемые поля.
4. Генерировать документы с уникальным автоматическим именем счета, например:
   - `invoice_20260205_0001.docx`
   - `invoice_20260205_0001.pdf`

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

После запуска откройте: <http://localhost:5000>
